# CalculadoraDatacenter

Proyecto base de calculadora para prueba técnica.

## Funcionalidades

- Suma (`+`)
- Resta (`-`)
- Multiplicación (`*`)
- División (`/`)
- Validación de división por cero
- Despacho por operador con `calculate(a, b, operator)`

## Ejecutar pruebas

```bash
python -m unittest -v
```
